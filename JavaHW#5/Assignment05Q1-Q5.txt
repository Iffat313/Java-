Context: A wrapper class is a type of class where we can assign a primitive value to an object of the class wrapper of whatever primitive type. Of course, seeing as there are 7 primitive types there are 7 wrapper primitive classes. With wrapper classes of any primitive type, we can either do autoboxing or autounboxing.

Autoboxing: Is when java automatically converts primitive value to an object of the class wrapper of a corresponding primitive type. Thus assigning the primitive value to an object of the class wrapper of the corresponding primitive type. 
Ex:
(Integer intObject = 2;; //shorthand notation) 
or
(Integer intObject = new Integer(2); //longer notation but both achieve the same idea)

Autoboxing: Is the reverse of autoboxing. Essentially, it is the automatic conversion of the wrapper object to a primitive data type. However, I see it as: “The unwrapping of the primitive value which was previously assigned to an object of the class wrapper of the same primitive type but it is now assigned to a variable of that same primitive data type. Of course, seeing this variable will no longer have access to methods of the wrapper class of whatever primitive type. 
Ex:
(int i = 1; //Now that you’ve learned autoboxing, we now recognize that were autoboxing almost anytime we declare and initialize a variable of a primitive type)
Or
(int i = new Integer(1));
